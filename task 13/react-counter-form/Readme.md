# 🔢 React Counter & Form Handling App (Vite + Tailwind)

This is a beginner-friendly yet production-ready React application built using **Vite** as the development environment. The app demonstrates two core concepts in React:

- A **Counter** with `useState` and event handlers
- A **Controlled Form** capturing user input with real-time state updates

It’s styled using **Tailwind CSS**, making it fast, clean, and responsive.

---

## 📦 Tech Stack

- ⚛️ **React** (Functional Components + Hooks)
- ⚡ **Vite** (for blazing-fast development and hot reload)
- 🎨 **Tailwind CSS** (for utility-first styling)
- ✏️ **JavaScript** (ES6+ syntax)

---

## 🚀 Features

### ✅ Counter Component
- Increment, decrement, and reset functionality
- State managed using React `useState`
- Buttons styled with Tailwind

### ✅ Form Handling Component
- Fields: Name, Email, Message
- Fully controlled form using `useState`
- Form data logged/displayed on submit
- Prevents default page reload
- Clean and responsive layout

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/react-counter-form.git
cd react-counter-form
````

### 2. Install dependencies


npm install
```

### 3. Run the development server


npm run dev
```

Open your browser and visit: [http://localhost:5173](http://localhost:5173)
